# Job Bot

Telegram бот для управления вакансиями и резюме через API платформы job-platform.

## Архитектура

Бот использует паттерны **Factory** и **Facade** для формирования HTTP-запросов к API. Поддерживает JWT-аутентификацию с автоматическим обновлением access-токенов.

## Безопасность токенов

- **hh.ru токены** хранятся и шифруются **только** на стороне API
- **Access-token** хранится в памяти процесса бота и используется в заголовке `Authorization: Bearer <token>`
- **Refresh-token** хранится в API, бот получает новый access-token через вызов `/auth/refresh`

## Переменные окружения

Бот получает переменные окружения через Docker Compose. Файлы `.env*` не хранятся в репозитории и подставляются контейнером при запуске.

Обязательные переменные:
- `BOT_TOKEN` - токен Telegram бота
- `API_URL` - базовый URL API (по умолчанию: `http://localhost:8000/api/v1`)

## Запуск

Бот запускается как часть платформы job-platform через единый `docker-compose.yml`:

```bash
docker-compose up
```

## Команды бота

- `/start` - приветствие и список доступных команд
- `/login` - получить ссылку на веб-авторизацию
- `/me` - информация о текущем пользователе
- `/resumes` - список резюме пользователя
- `/select_resume <id>` - выбрать активное резюме
- `/publish_resume <id>` - опубликовать/поднять резюме
- `/vacancies` - список вакансий
- `/refresh` - обновить access-token

## Обработка ошибок

При получении HTTP статусов 401/403 бот отвечает сообщением:
> "Не авторизован. Подключите аккаунт через /login"

## Разработка

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Запуск тестов

#### Unit тесты

```bash
# Только unit тесты (быстрые, без зависимостей)
pytest -m unit -v
```

#### Интеграционные тесты

**Простой способ** (рекомендуется):
```bash
# Автоматическая проверка зависимостей и запуск
python run_integration_tests.py
```

**Ручной запуск**:
```bash
# Интеграционные тесты (требуют docker-compose)
pytest -m integration -v
```

> **Важно**: Интеграционные тесты автоматически запускают docker-compose окружение, что требует:
> - Установленный Docker и Docker Compose
> - Настроенные переменные окружения (`.env.dev`, `.env.hh.dev`)
> - Доступ к интернету (для HH.ru OAuth тестов)
> - До 3-5 минут на запуск окружения

#### Все тесты

```bash
# Все тесты
pytest -v
```

### Структура API Facade

- `RequestFactory` - фабрика для создания HTTP запросов (GET, POST, PUT)
- `ApiFacade` - фасад для работы с API, управление токенами

### Добавление новых команд

1. Добавить метод в `ApiFacade`
2. Создать обработчик в `bot.py` с декоратором `@dp.message(Command("command_name"))`
3. Обновить справку в `/start`
