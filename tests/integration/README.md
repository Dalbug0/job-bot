# Интеграционные тесты

Интеграционные тесты проверяют работу job-bot API в реальном docker-compose окружении.

## Запуск интеграционных тестов

### Предварительные требования

1. **Docker и Docker Compose** должны быть установлены и запущены
2. **Переменные окружения** должны быть настроены (`.env.dev`, `.env.hh.dev`)
3. **База данных** должна быть доступна

### Запуск всех тестов

```bash
# Из директории job-bot
cd job-bot

# Запуск только интеграционных тестов
python -m pytest tests/integration/ -v

# Или с маркером
python -m pytest -m integration -v
```

### Запуск только unit тестов

```bash
# Только unit тесты
python -m pytest -m unit -v
```

### Запуск всех тестов

```bash
# Все тесты (unit + integration)
python -m pytest -v
```

## Что проверяют интеграционные тесты

### Эндпоинты авторизации

1. **`/api/v1/auth/login`** - проверка доступности эндпоинта
2. **`/api/v1/auth/refresh`** - проверка структуры ответа для обновления токенов
3. **`/api/v1/auth/hh/login`** - проверка редиректа на HH.ru OAuth
4. **`/api/v1/auth/hh/callback`** - проверка обработки OAuth callback

### API доступность

1. **`/docs`** - проверка доступности Swagger документации
2. **`/openapi.json`** - проверка доступности OpenAPI схемы
3. **CORS заголовки** - проверка настроек CORS

## Процесс работы

1. **Запуск docker-compose** - автоматически поднимаются все сервисы (API, БД, бот)
2. **Ожидание готовности** - тесты ждут, пока API станет доступным (до 2.5 минут)
3. **Выполнение запросов** - отправка реальных HTTP запросов к API
4. **Проверка ответов** - валидация статусов и содержимого ответов
5. **Остановка контейнеров** - автоматическая очистка после завершения

## Переменные окружения

- `API_BASE_URL` - базовый URL API (по умолчанию: `http://localhost:8000`)

## Обработка ошибок

Если API не поднимается в течение 2.5 минут, тесты падают с подробным сообщением и логами контейнера.

## Примеры запуска

```bash
# Запуск с подробным выводом
python -m pytest tests/integration/ -v -s

# Запуск конкретного теста
python -m pytest tests/integration/test_auth_integration.py::TestAuthIntegration::test_auth_login_endpoint_available -v

# Запуск с остановкой на первой ошибке
python -m pytest tests/integration/ -x -v
```
